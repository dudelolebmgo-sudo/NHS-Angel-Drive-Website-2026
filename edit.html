1. Connect to GitHub

Publishing saves data.json to the repository, and GitHub Pages updates the site within a minute or two. The token stays in this browser only.

How to get a token (one time, about 2 minutes)
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens, and choose Generate new token.
  2. Under Repository access, pick Only select repositories and choose this site's repository.
  3. Under Repository permissions, set Contents to Read and write. Leave everything else alone.
  4. Set the expiration to after the drive ends, generate it, and paste it above.
